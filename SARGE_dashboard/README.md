# SARGE dasboard

The SARGE_dashboard directory includes all code, data, and functions needed to run a real time data dashboard. These materials are intentionally designed to be modular and reproducible for other applications.

To modify these files for your own system, the main change you need to make is to updated the files in `./config` to include the correct file paths, column names, and colors for your application. Then, run `app.R` to view real-time data. To include your own photos, you will need to add photos in `./www/images` and update file paths in `app.R`.
